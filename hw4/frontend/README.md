# Campus Customs — frontend

React 19 + Vite + TypeScript storefront and chat widget. See the [project README](../README.md) for full setup.

```bash
npm install
npm run dev      # http://localhost:5173 (proxies /api, /media, /chat to the FastAPI backend on :8000)
npm run build    # type-check + production build
npm run lint     # oxlint
```
